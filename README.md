### Breve descrição do projeto 2:
**Informações:** Projeto simples para demonstrar o uso do Markdown na formatação de textos e criação de documentações no Github. O Github é uma plataforma usada para armazenar e gerenciar projetos com controle dee versão. Nele, é possível criar repositórios, enviar arquivos, resgistrar alterações com commits e colaborar com outros usuários de forma organizada. As __*Issues*__ são usadas para relatar problemas, sugerir melhorias ou organizar tarefas do projeto. Os __*Pull Requests*__ permitem enviar alterações no código para revisão antes de serem integradas ao repositório principal, facilitando a colaboração eo controle  de mudanças. O __*Fork*__ é uma cópia de um repositório para a sua conta github, permitindo fazer alterações de forma independente e contribuir com o projeto original.
